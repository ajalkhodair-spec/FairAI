# Security Policy

This repository is a research MVP and has not received an external security audit.

Do not use the current implementation for mainnet or high-value production deployments without:

- independent smart-contract review;
- verifier and ZK integration review;
- key-management review;
- IPFS availability and pinning review;
- operational monitoring and incident-response procedures.

If you find a security issue, do not disclose exploit details in a public issue. Contact the repository maintainer privately or open a minimal public issue that requests a private security discussion.
